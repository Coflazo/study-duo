# Code of conduct

Study Duo follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, criticise ideas and not people, and help newcomers. Harassment, insults and personal attacks are not welcome in issues, pull requests or discussions.

To report a problem, open a private security advisory from the repository's Security tab and mark it as a conduct report, or contact the maintainer through their GitHub profile. Reports are handled privately and quickly.
