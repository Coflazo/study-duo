# S3 Overlay Clock, Phase Words and Phrase Bank Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The corner clock on every page and the big phase words at each phase change, in code, matching the approved Figma, plus the design tokens, the bundled fonts and a 500+ line phrase bank.

**Architecture:** Design tokens are exported from Figma to `design/tokens.json` and turned into `src/ui/tokens.css` by a small generator. The overlay is one content script with two closed shadow roots: the clock capsule (top right, 7-segment digits drawn as SVG from shared segment geometry) and the announcement layer (centered plain text with a halo). The content script only reads storage and sends `tick`; the background picks the phrase from a persisted shuffle bag and sends it to the active tabs, falling back to a notification when no page can show it.

**Tech Stack:** WXT 0.21 content scripts, TypeScript, plain DOM + CSS (no framework in pages), Vitest + fake-browser, Playwright with Chrome for Testing.

**Spec:** `docs/superpowers/specs/2026-10-07-study-duo-design.md` (Features v0.1: overlay clock, phase announcement; Design system v0.1; Security & privacy items 4 and 5). Design: Figma `mswojkCHnwTQOvOcsn3vO5`, pages Overlay, LED, Screens.

## Global Constraints

- No network. Fonts and every asset are bundled; `web_accessible_resources` lists only the fonts the overlay needs, with `use_dynamic_url: true`.
- Content script UI lives in closed shadow roots; page text is never read; all text is set with `textContent`; no `innerHTML`.
- The background accepts only `{ type: 'tick' }` from content scripts (messages with `sender.tab`); every other timer command must come from an extension page (S1 ruling).
- Copy: zero em or en dashes, short lines, no AI filler words; humanizer, voice and stop-slop rules.
- Motion: announcement enter 400 ms (opacity, scale 0.98 to 1, blur 4px to 0, `cubic-bezier(0.23, 1, 0.32, 1)`), hold 1600 ms, leave 1800 ms opacity `ease`; clock dim/near 180 ms opacity only; reduced motion keeps opacity only and stops the colon blink.
- Approved Figma wins over generic craft rules (ruling: the 3px red current-row rail stays because Cagan approved it).
- Responsive: phase words use `clamp()` and wrap within 90vw; the clock stays 16px from the corner at any size.

## Review Focus

1. **Hostile pages:** a page that overrides `HTMLElement.prototype`, sets `* { all: unset }` or uses a strict CSP must not break or restyle the clock. Test: overlay renders inside a page with aggressive global CSS.
2. **Many tabs:** only visible tabs tick; hidden tabs run no interval. Test: interval stops on `visibilitychange` hidden.
3. **Clock under the cursor:** a dim clock must never steal clicks from the page beneath. Test: `pointer-events: none` while dim.
4. **Phrase repeats:** no line repeats within a moment until the list is exhausted, across browser restarts. Test: bag persisted in storage.
5. **Spoofed messages:** a page posting messages or a content script sending `skip`/`reset` must not control the timer. Test: background gate.

```js
#!/usr/bin/env node
// Turns the Figma variable export (design/tokens.json) into src/ui/tokens.css.
import { readFileSync, writeFileSync } from 'node:fs';

const cssName = (n) => n.replace(/\//g, '-');
const unit = (name, v) => typeof v !== 'number' ? v : name.startsWith('motion/duration') ? `${v}ms` : `${v}px`;
const value = (name, v) => (typeof v === 'string' && v.startsWith('@') ? `var(--${cssName(v.slice(1))})` : unit(name, v));
const FONT_FALLBACK = { 'font/family/ui': "system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif", 'font/family/mono': "ui-monospace, 'SF Mono', Menlo, Consolas, monospace" };

export function toCss(tokens) {
  const light = [], dark = [];
  for (const [collection, vars] of Object.entries(tokens)) {
    for (const [name, modes] of Object.entries(vars)) {
      if (collection === 'Type') { light.push(`  --${cssName(name)}: '${modes.Value}', ${FONT_FALLBACK[name]};`); continue; }
      if (collection === 'Color') {
        light.push(`  --${cssName(name)}: ${value(name, modes.Light)};`);
        dark.push(`    --${cssName(name)}: ${value(name, modes.Dark)};`);
        continue;
      }
      light.push(`  --${cssName(name)}: ${value(name, modes.Value)};`);
    }
  }
  const darkBlock = dark.join('\n');
  return [
    '/* Generated from design/tokens.json by scripts/tokens-to-css.mjs. Do not edit by hand. */',
    ':root {', ...light, '}',
    '@media (prefers-color-scheme: dark) {', '  :root:not([data-theme="light"]) {', darkBlock, '  }', '}',
    ':root[data-theme="dark"] {', darkBlock.replace(/^ {4}/gm, '  '), '}', '',
  ].join('\n');
}

if (import.meta.url === `file://${process.argv[1]}`) {
  writeFileSync('src/ui/tokens.css', toCss(JSON.parse(readFileSync('design/tokens.json', 'utf8'))));
}
```

Voices mixed on purpose: plain ("Study time."), exam hall ("Pens up.
